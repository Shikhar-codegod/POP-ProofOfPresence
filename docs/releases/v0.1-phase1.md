# POP v0.1-phase1

## Summary

This release closes Phase 1 of ProofOfPresence: an edge person-counting pipeline, authenticated telemetry API, Docker Compose infrastructure, seed data, idempotency, accuracy tooling, and CI closeout.

## Highlights

- Python 3.10-compatible edge pipeline.
- Script-relative configuration with `config.local.yaml` and `POP_DEVICE_KEY` precedence.
- Deterministic `--start-time` support for repeatable ingestion.
- Real-clip smoke verification artifacts.
- Robust accuracy ground-truth validation and label-frame export.
- PowerShell and Bash verification scripts.
- Phase 1 repository cleanup and Apache-2.0 license.

## Release validation

Run Ruff and edge tests:

```powershell
pop\edge\.venv\Scripts\python.exe -m ruff check --config pyproject.toml pop/backend pop/edge pop/ml
pop\edge\.venv\Scripts\python.exe -m pytest -c pyproject.toml pop/edge/tests -q
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify_phase1.ps1
```

Live Docker verification requires Docker Desktop and `POP_ADMIN_EMAIL`, `POP_ADMIN_PASSWORD`, and `POP_DEVICE_KEY`.

## Known limitations

- Accuracy metrics remain pending manual labelling.
- Live 201/200 and database row-count proof was not available when Docker Desktop was unreachable.
- The supplied clip is short and overhead footage may undercount with the COCO-pretrained detector.
